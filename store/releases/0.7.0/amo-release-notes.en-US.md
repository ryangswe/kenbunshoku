Card hovers no longer start in a tab you are not looking at. A video that starts playing in a background tab starts them when you bring the tab to the front, if it is still playing then, and so does switching card hovers on while the tab is in the background. On Twitch, the Following and Creator Camp pages now start card hovers when you first point at the video. A turned card near the edge of the video is now outlined turned instead of with an upright box. When the page removes the card's tooltip, the card on show comes back at the next pointer move over the video. A change to the popup's switch made while a page is still opening is no longer lost. If the recognition worker restarts while the pointer rests, a rest that already had its one picture after a slow load no longer gets a second one.
